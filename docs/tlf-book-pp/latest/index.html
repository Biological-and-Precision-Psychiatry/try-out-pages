Welcome

This Quarto book contains tables, listings and figures for statistical analyses of the DEXA-PSYCH trial. All outcomes are reported from day 0 to day 28. Long term follow-up (until 6 months after baseline) will be presented separately.

The DEXA-PSYCH trial has EU Trial registration number 2022-501428-45-00 with WHO universal Trial Identifier U1111-1280-7614.

The Trial protocol is available here in its latest version and an earlier version is presented in Rømer et al (2025)

The Statistical Analysis Plan (SAP) was archived and locked in a persistent and immutable Zenodo DOI prior to unblinding of the randomization list. The time of unblinding coincides with locking of the database and is called database lock (DBL).

All analysis code is openly available at the github repository https://github.com/Biological-and-Precision-Psychiatry/DEXA-PSYCH-internal. The code is released in two versions: pre-dbl-v1.0 and post-dbl-v1.0. Each version is archived in Zenodo DOIs and any differences between the two version of the code base is documented. For further information see the traceability section below.

This TLF-book is produced in two versions:

  1. Primary Publication: This version documents all summaries and statistical analyses for safety and efficacy endpoints presented in the primary publication as documented in the SAP and trial protocol. This version is archived in a Zenodo DOI here.
  2. Clinical Trial Protocol (CTR): This version includes all content reported in the primary publication version but also presents results for additional secondary outcomes. Contents for the secondary outcomes will be released upon publication of secondary papers presenting the additional secondary outcomes. This version of the TLF-book is archived in a Zenodo DOI here.

You are currently reading the Primary Publication version of the TLF-book.

Organization of the book

This book is organized in four parts:

  • OVERVIEW:
    • Describes patient inclusion, characteristics, and retention and treatment persistence during the trial. It also illustrates and summarizes results of analyses performed in the following parts of the book.
  • POLICY ESTIMAND
    • Contains all summary tabulations, statistical analysis tables and figures for the treatment policy (primary) estimand.
  • EFFICACY ESTIMAND:
    • Contains all summary tabulations, statistical analyses tables and figures for the treatment efficacy (secondary) estimand.
  • SAFETY
    • Contains all statistical analysis tables and figures for safety endpoints, tabulations of adverse events, and listings of events of particular interest.

Trial data were captured using REDCap electronic data capture tools hosted at The Capital Region of Denmark. REDCap (Research Electronic Data Capture) provides audit trails for tracking data manipulation with complete log-files stored on secure electronic and physical drives.

The raw trial data exported from REDCap in the form of a .csv file and an .r file are held on a secure drive and are not publicly available due to data privacy restrictions. The checksums listed above allow an authorized auditor with access to the data to confirm that the same files were used.

Computing environment

The following list describes the computing environment that produced this Quarto book:

  • R version 4.6.0 (2026-04-24 ucrt)
  • Platform: x86_64-w64-mingw32/x64
  • Running under: Windows 11 x64 (build 26200)
  • Quarto version: 1.9.38
  • Pandoc version: 3.8.3

The repository is equipped with an renv.lock-file which makes the R-package environment reproducible by capturing all versions and inter-dependencies. To re-create the R environment used to produce this book, clone the repository, open R and run renv::restore(). For further information see the renv package homepage.

How to cite this work

For citation in published works, please use the relevant DOI(s) listed above and the citation information available in each of them. The code base repository also has citation information available in a CITATION.cff file. A link to the primary publication is provided in the GitHub repository here and also linked to in the meta data of the DOIs provided above. Because this book is compiled prior to release of the primary publication a direct link cannot be included in this book.
